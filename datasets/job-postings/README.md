## Description

15,000 synthetic tech and business job postings spanning 10 job titles across 8 industries, with salary ranges, required skills, experience levels, remote work type, company size, and job descriptions. Covers the 2023-2025 job market for Data Scientists, ML Engineers, Software Engineers, Data Analysts, Product Managers, and more.

Built for: salary prediction (regression on salary_min/max), job title classification from description (NLP), skills extraction and analysis, remote work trend analysis, and job market exploratory data analysis. The description field enables NLP tasks while structured fields enable tabular ML.

Notable features: salary ranges encode realistic correlations (senior > entry, enterprise > startup, ML roles > average, remote premium); required_skills is pipe-separated for easy parsing; experience_level × company_size interaction drives compensation; applications field enables demand modeling. All data is synthetic.
